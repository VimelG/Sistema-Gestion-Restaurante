# Registro de Cambios y Avances del Proyecto

## Sistema de Gestión para Restaurante (SGR)

Este documento presenta cinco avances realizados durante el desarrollo académico del Sistema de Gestión para Restaurante (SGR), correspondiente a la asignatura Ingeniería de Software I.

## 1. Registro de avances

| N.º | Avance realizado | Descripción |
|---|---|---|
| 1 | Definición de requisitos | Se documentaron seis requisitos funcionales y cinco no funcionales, estableciendo las necesidades y características del sistema. |
| 2 | Elaboración de diagramas UML | Se desarrollaron y organizaron los diagramas de casos de uso, clases, secuencia y actividades para representar la estructura y el comportamiento del sistema. |
| 3 | Definición de arquitectura | Se documentó una arquitectura de tres capas, separando la presentación, la lógica de negocio y el acceso a datos. |
| 4 | Organización del repositorio | Se actualizaron los archivos README.md y se crearon carpetas para clasificar requisitos, diagramas UML y arquitectura. |
| 5 | Control de versiones en GitHub | Se registraron cambios mediante commits en la rama main, manteniendo un historial de las actualizaciones del proyecto. |

## 2. Control de cambios

Los avances fueron organizados y documentados como parte del cierre técnico académico del SGR.

GitHub permite conservar el historial de modificaciones realizadas, identificar los archivos actualizados y mantener una versión controlada de la documentación del proyecto.

## 3. Estado actual

El proyecto cuenta con documentación de requisitos, diagramas UML, descripción de arquitectura y un repositorio organizado en GitHub.

La implementación completa de las funcionalidades y las pruebas técnicas permanecen sujetas a verificación.
